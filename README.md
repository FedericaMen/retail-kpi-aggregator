# 📊 Retail Multi-Store KPI Aggregator & Automator

A Python automation tool developed to streamline the extraction, cleaning, and aggregation of sales and inventory data across multiple retail store locations.

## 🎯 Business Context & Objective
In multi-location retail and distribution environments, monitoring operational performance and inventory levels often requires manually merging scattered report files generated by point-of-sale (POS) or ERP systems.

This project demonstrates how a targeted Python script can:
* **Eliminate manual reporting time** by automating multi-store data aggregation.
* **Minimize human error** during data manipulation and formatting.
* **Generate instant operational KPIs** including revenue, transaction count, and average order value (AOV) per store.

## 🚀 Core Features
* **Data Ingestion:** Reads structured data feeds from individual retail locations.
* **KPI Computation:** Automatically calculates key performance metrics at both store and group level.
* **Error Handling:** Safely handles zero-transaction edge cases to prevent division errors.
* **Operational Reporting:** Produces clean, executive-ready summaries in the console.

## 🛠️ Tech Stack
* **Python 3.10+**
* **Data Structures:** Lists, Dictionaries, and Functions for modular data processing.
